# Supplementary calibration-pool influence protocol

This supplements experiment E's predeclared dates and D's uncertainty audit. It is declared after the primary v2 tables have been seen, **before executing this diagnostic**. It is explicitly post-primary exploratory work, not a new confirmation or interval-selection exercise. The primary v2 bundle and v1 remain unchanged.

For the original median_12 specification at the same 16 reporting-cutoff origins, reconstruct the prior-only prequential residual pool. Reproduce the original centered circular bootstrap exactly, then separately omit the residual **labeled with** October 2019, November 2020 or September 2025 if that residual exists in the fitted prefix. Recenter the remaining pool and use the same 5,000 paths and seed. Do not refit point forecasts or change any actual, primary training observation, v1 output or primary v2 interval.

This isolates calibration-pool influence; it is different from the main diagnostic that masks a date during trend/seasonality fitting. Downstream residuals affected by an earlier event are not removed. If a date never had an eligible prequential residual, or is later than the fitted prefix, record **not_in_residual_pool** and do not manufacture an altered interval. Report removed residual's fraction of original uncentered residual sum of squares, pool skewness, widths and empirical coverage. Compare the original bootstrap only on the identical eligible origins for each date. The evaluated actuals never enter interval construction; coverage is descriptive, with overlapping windows and no tail guarantee. No preferred alternative is selected from these scores.

Store this diagnostic in its own immutable output directory, with protocol/source hashes, v1 and primary-v2 manifest hashes, execution timestamp and a separate integrity manifest. Findings can explain whether the broad original intervals depend on a small number of extraordinary residuals; they cannot establish that omitting such residuals is appropriate.
