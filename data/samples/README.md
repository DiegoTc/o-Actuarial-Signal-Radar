# Official CNBS deterministic excerpts

Each CSV contains 24 real source records from the initial official datastore download. Source URL, resource ID, full-file checksum and selection rule are recorded in the corresponding metadata JSON. The `sha256` field checks the sample bytes; `source_sha256` checks the full original download.

These files test schema and parsing only. Use the full download workflow in the root README for date coverage, profiling and candidate comparison.
